# Livro Motivacional

Um livro digital de motivação com frases inspiradoras e design moderno (roxo/azul/branco).
Pronto para subir no GitHub e fazer deploy (Vercel, Netlify, etc).

## Como usar localmente

```bash
npm install
npm start
```

## O que inclui
- React
- TailwindCSS (config pronta)
- Framer Motion (animação)
- Componente `LivroMotivacional.jsx`
